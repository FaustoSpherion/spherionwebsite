# Content Audit — Current Spherion Website

## Main findings

1. The current public navigation is too small for the evolved project. It mainly exposes Home and About, while the project now needs separate paths for Geometry, Algebra, SOS Kernel, Resources, Applications, Get Involved, and Contact.

2. The Home page contains many good themes, but they are blended into one long page: Spherion Geometry, Spherion Algebra, downloadable documents, Kindle/book links, and contact language.

3. The About page still reflects an early “Spherion Metrics” stage. It includes useful material on spherical subdivision and uncertainty, but it also contains old coordinate-based language, rough equations, placeholder text, and mixed beginner pop-up content.

4. The current giving page appears to use generic template copy. It should be replaced by a Get Involved page focused on research collaboration, formal review, software implementation, diagram development, and education.

5. The redesigned site should avoid sounding like a finished accepted mathematical system. It should present Spherion as an original, evolving research framework that invites critique and formalization.

## Recommended new structure

- Home: concise public explanation and routing.
- About: origin, creator, evolution from Metrics to Geometry/Algebra/Kernel.
- Geometry: sphere-first principles, zones, refinement, adjacency, motion.
- Algebra: zone codes, fan-out, collapse, weighting, probabilistic inclusion.
- SOS Kernel: implementation direction and testable computation core.
- Applications: research directions rather than completed promises.
- Resources: books, papers, diagrams, source code, glossary.
- Get Involved: replace generic donation language.
- Contact: direct inquiry and collaboration path.
