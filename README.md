# Spherion Website Redesign Prototype

This package is a static HTML/CSS prototype for a redesigned Spherion website.

## Pages
- Home
- About
- Spherion Geometry
- Spherion Algebra
- SOS Kernel
- Applications
- Resources
- Get Involved
- Contact

## How to preview
Open `index.html` in a browser. All pages are static and require no build step.

## Migration notes
- Replace placeholder book and document buttons in `resources.html` with the current Google Drive, Dropbox, Amazon, and PDF links.
- Replace the `mailto:` form in `contact.html` with the form handler used by your website platform.
- The current content is written in English. A Portuguese version can be made by duplicating the pages or adding a language switch.
