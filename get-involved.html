Get Involved

Help test, formalize, implement, and explain Spherion.

This page replaces the generic donation-page language with a serious invitation to participation. Spherion needs critique, formal review, software testing, diagrams, translations, and educational material.

Mathematicians

Review the axioms, test definitions, identify hidden Euclidean assumptions, and help improve notation.

Developers

Prototype data structures, refine the SOS Kernel, write tests, and explore deterministic implementations.

Physicists

Examine whether probabilistic inclusion and observer-relative motion offer useful conceptual analogies or models.

Designers

Create diagrams that explain zones, layers, adjacency, refinement, and observer-dependent motion.

Educators

Help translate Spherion into accessible lessons for students, general readers, and young learners.

Readers

Ask questions, point out unclear passages, and help identify where the theory needs better explanation.

Suggested collaboration tracks

  • Formal review of the axiom system
  • Comparative notes with HEALPix, S2, HTM, graph geometry, and geometric deep learning
  • Implementation tests for refinement and collapse
  • Diagram and animation package for the website
  • Portuguese/English editorial harmonization
